# Security Policy

## Supported versions

Security fixes are provided for the current `main` branch and the latest tagged release.

| Version | Supported |
|---|---:|
| 2.0.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email [lucaszhouc@gmail.com](mailto:lucaszhouc@gmail.com) with the subject `[SECURITY] Tribunal` and include:

- the affected version;
- a minimal reproduction or proof of concept;
- the expected impact;
- any suggested mitigation.

This is a single-maintainer project, so an initial response may take up to seven days. Please allow time for a fix before public disclosure.

Tribunal is an instruction package, not a sandbox. It cannot grant permissions that the host agent or operating environment does not already have. Review any third-party changes before installing them.
